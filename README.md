# 考勤工时管理系统 - 前端

基于 Vue 3 + Vite + Element Plus 的考勤工时管理系统前端。

## 技术栈

- Vue 3 (Composition API)
- Vite
- Element Plus
- Pinia (状态管理)
- Vue Router 4
- Axios
- ECharts 5

## 快速开始

```bash
npm install
npm run dev
```

## 构建生产���本

```bash
npm run build
```

构建产物输出到 `dist/` 目录。

## 项目结构

```
src/
├── api/           # API 请求封装
├── assets/        # 静态资源
├── components/    # 共享组件
├── router/        # 路由配置
├── stores/        # Pinia 状态管理
├── views/         # 页面组件
├── App.vue        # 根组件
├── main.js        # 入口文件
└── style.css      # 全局样式
```

## 功能模块

- 工时管理（日历视图、填报）
- 工时报表（饼图、Excel 导出）
- 员工管理
- 部门管理
- 历史查询
- 系统配置（节假日管理）
